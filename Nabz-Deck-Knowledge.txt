0. PRODUCT ONE-LINER
================================================================================
Nabz (Urdu نبض, "pulse") is an Urdu-first, voice-first AI health triage
web + mobile app for Pakistan. A patient describes symptoms in Urdu, Roman
Urdu, English, or a code-switched mix — by voice or by typing — and Nabz
returns a structured triage in the same language: what the symptoms most
likely mean, red flags to watch for, urgency level, and concrete next steps.

Nabz is not a doctor. It is the layer that meets patients where they already
are — on WhatsApp voice notes, on low-cost Android phones — and gets them
to the right care faster.

- ~90       — mental-health professionals for 240 M people (est., WHO)
- ~40%      — adult literacy in written English (est., UNESCO)

Voice-native and voice-first. Two of three target users have limited
written English. All three own a phone.

   Won't queue at a clinic for a day of wages.

3. Student in crisis
   Mental-health emergency at 3 am, no one to call.

7. REQUEST PATH — SYMPTOM VOICE NOTE, ELEVEN STEPS
================================================================================
1.  Patient taps mic on guest chat page.
2.  Browser / WebView calls navigator.mediaDevices.getUserMedia with
    ideal-constraint audio; MediaRecorder writes audio/webm blob.
3.  Client POSTs blob multipart to /api/voice/transcribe.
4.  voice_stt.py checks mock mode, then tries Qwen3.5-Omni via DashScope
    (audio inlined as data-URL).
5.  On Qwen failure (quota, timeout, empty transcript) falls back to
    OpenAI Whisper with the raw bytes.
6.  Endpoint returns {transcript, language, provider}. Never a fabricated
    transcript in live mode.
7.  Client posts transcript to /api/triage; server runs deterministic
    emergency + mental-health detectors first.
8.  If neither pattern fires, Qwen3.7-plus generates a structured JSON
    triage (symptoms, red flags, urgency, plan).
9.  Cost is metered against per-account (or per-guest) USD budget; overshoot
    switches to fallback or refuses.
10. Response rendered Urdu-first with bilingual bullets and, on emergency,
    a 1122-call banner.
11. Patient optionally taps TTS; client streams Qwen3.5-Omni Urdu audio back.

================================================================================
Role             Primary                Fallback              Cost lever
--------------------------------------------------------------------------

Image OCR        qwen3.7-plus (VL)      qwen-vl-ocr           45 s timeout

Budget caps (hard, server-enforced):
  NABZ_REGISTERED_AI_BUDGET_USD = 0.50  (per registered account)
  NABZ_GUEST_AI_BUDGET_USD      = 0.30  (per anonymous session)

Every AI call is metered in USD before it is issued. If the running spend on
the current account plus the estimated cost of the next call would exceed
the cap, the request is served by the cheaper fallback if one exists,
otherwise refused with a graceful message. The client cannot raise the cap.

9. SAFETY GUARDRAILS — THREE DETERMINISTIC LAYERS
================================================================================
Layer                  | Fires when                            | Action
----------------------------------------------------------------------------
Emergency              | Cardiac / stroke / obstetric /        | Return 1122
                       | poisoning / trauma phrase             | banner + safe
                       |                                       | text · SKIP LLM
Mental-health          | Suicidal / self-harm phrase           | Warm response
(immediate)            | · negation-aware 35-char window       | + helpline
                       |                                       | · SKIP LLM
Mental-health          | Softer distress cues                  | Steer LLM
(distress)             |                                       | toward
                       |                                       | supportive tone

Negation example: "میں خودکشی نہیں کروں گا" ("I will not commit suicide")
does NOT fire the immediate MH detector — the 35-char negation window
catches "نہیں" ("not") preceding the crisis phrase.

Design principle: safety is enforced in code, not prompts. Nothing a patient
(or an attacker impersonating one) types will bypass the deterministic
detectors. The LLM sees text only after detectors have had first look.

11. AUTH MODEL
================================================================================
Two JWT kinds so a stolen doctor-handoff link cannot be replayed as an
account login, and vice-versa.

Kind      | Issued when                    | Scope                        | Lifetime
------------------------------------------------------------------------------
account   | After OTP verify or password   | Read/write own account       | Session
          | login                          | and its profiles             | (sessionStorage)
handoff   | Patient generates doctor link  | Read one specific triage     | Short,
          |                                | session only                 | single-use

Family isolation — every authed request carries an active profile ID. The
server rejects any query that tries to read a profile the account does not
own with 403. Vault files live under a per-profile directory.

17. KNOWN LIMITATIONS
================================================================================
- SQLite is single-writer; migrate to Postgres for production concurrency.
- In-process rate-limit deque does not survive a restart or scale to
  multiple workers — needs Redis.
- No refresh-token rotation yet; access tokens are session-scoped.
- Password reset flow deferred; OTP hardening (per-account attempt cap)
  deferred.
- Nominatim disabled on live (rate limits); currently rely on client-provided
  coordinates only.
- Real OTP provider (Twilio Verify) planned instead of Gmail SMTP for WhatsApp.
- Accessibility pass — screen-reader labels for RTL controls, keyboard-only
  navigation still to complete.
- Formal medical review of safety-detector patterns pending.

21. LIKELY JUDGE QUESTIONS + CANONICAL ANSWERS
================================================================================
Q: Why Alibaba Qwen and not GPT?
A: Qwen3.7-plus and Qwen3.5-Omni carry Urdu, Roman Urdu, and mixed
   code-switched Pakistani speech natively — no MT hop, no meaning loss.
   GPT-4o-mini is our budget-capped fallback: same schema, different
   provider, so a Qwen quota blip does not take the demo down.

Q: How do you handle a medical emergency?
A: Deterministic pattern list runs BEFORE the LLM. When it fires — cardiac,
   stroke, obstetric, poisoning, trauma cues — we skip the LLM entirely and
   return a fixed safe response with a 1122 call banner. Guardrails cannot
   be prompt-injected because they are in code, not in a prompt.

Q: What if a suicidal patient uses Nabz?
A: A negation-aware mental-health detector fires on immediate crisis phrases
   in Urdu and English, with a 35-character negation window so
   "میں خودکشی نہیں کروں گا" does not misfire. When it fires we return a
   warm, culturally-appropriate response with a helpline and skip the LLM.

Q: How much does one triage cost?
A: A typical text-only triage is a few tenths of a US cent on Qwen. Voice
   adds STT — still under one cent per turn. Hard USD cap per account ($0.50)
   and per guest ($0.30), server-side; the client cannot raise it.

Q: What happens if Qwen goes down mid-demo?
A: Speech: automatic Whisper fallback with the same audio bytes; the response
   body reports the provider so we can see it happened. Text: gpt-4o-mini
   with the same JSON schema. Both were tested by killing the primary key
   in a test.

Q: Is my voice sent to a Chinese server?
A: Voice is sent to Alibaba DashScope over TLS for transcription. We do not
   store audio on our server — it is streamed in-memory and discarded once
   the transcript returns. For patients who prefer, the fallback path uses
   OpenAI Whisper.

Q: How is a family member's data isolated?
A: Every request carries an active profile ID. The server rejects any query
   that tries to read a profile the current account does not own with 403.
   Vault files live under per-profile directories.

Q: How does the doctor handoff work?
A: Patient consents in-app; server mints a short-lived, single-use JWT of
   a distinct kind ("handoff", not "account"). Doctor opens the link — no
   signup — and gets read-only access to that one session. Replay is refused.

Q: Why sessionStorage instead of localStorage for the JWT?
A: A health session should not survive a browser profile migration or a
   shared device. sessionStorage clears on tab close by design.

Q: What is your test story?
A: End-to-end pytest suite covering: never-fabricate invariant (503 when
   both STT providers dead), Whisper fallback happy path, handoff token
   kind check, rate-limit trigger, and the deterministic emergency + MH
   detectors.

Q: Why an APK and not just a PWA?
A: Pakistani Android users install APKs directly; the WhatsApp habit is to
   receive the file, not visit a URL. Capacitor lets us ship both from one
   React codebase — no separate mobile team, no split roadmap.

Q: What is your fallback if the demo Wi-Fi dies?
A: The PWA installs and boots offline; typed triage works with a graceful
   "voice unavailable" if STT cannot reach the network. The APK bundles the
   entire frontend; only the AI calls need connectivity.
