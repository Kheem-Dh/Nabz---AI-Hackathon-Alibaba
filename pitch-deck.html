05

Not another symptom chatbot — a safety-engineered clinical layer

🛡️

Safety runs before the model

Emergency & mental-health cues are caught in code — guardrails can't be prompt-injected away. Negation-aware, so “میں خودکشی نہیں کروں گا” isn't flagged.

🗣️

Native Urdu, no translation

Qwen carries mixed Urdu/English directly — no MT step, no meaning loss on code-switched speech.

💊

Evidence-gated medicine

The model may only propose; a server resolver validates against a WHO/FDA catalog + live DailyMed, with allergy/pregnancy/duplicate filters. It never invents a drug or dose.

🔀

Redundancy + cost cap

Qwen primary → OpenAI failover, with a per-user budget ledger. A quota blip never takes triage — or the demo — down.
